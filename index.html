Personal Voice Engine

Mac with Apple chip (M1 or newer), macOS 14 or newer.

  1. Open the zip and drag PersonalVoiceEngine into Applications.
  2. Open it. If macOS says it cannot be opened: System Settings → Privacy & Security → scroll down → Open Anyway.
  3. Allow Microphone and Speech Recognition when asked.
  4. System Settings → Privacy & Security → Accessibility → turn on PersonalVoiceEngine.
  5. Hold Right Option, speak, let go.

The first launch downloads a 1.7 GB language model in the background. No account or API key needed.
